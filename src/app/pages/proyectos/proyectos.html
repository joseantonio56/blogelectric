VentasBar

Sistema de gestión para bar y restaurante

Sobre el proyecto

VentasBar es una aplicación de gestión para bares y restaurantes desarrollada como un proyecto Full Stack.

El proyecto combina un frontend desarrollado con Angular con un backend desarrollado con Java y Spring Boot, conectado a una base de datos MariaDB.

El objetivo es disponer de una aplicación capaz de gestionar productos, clientes, mesas, ventas y comandas desde una misma plataforma.

Tecnologías utilizadas

Angular TypeScript Java Spring Boot MariaDB REST API WebSocket Bootstrap

1. Pantalla de acceso

Inicio de sesión

La aplicación comienza con una pantalla de acceso desde la que el usuario puede identificarse antes de entrar al sistema.

El proceso de autenticación se comunica con el backend desarrollado con Spring Boot para comprobar las credenciales del usuario.

El sistema también permite trabajar con diferentes roles de usuario, de manera que cada usuario pueda disponer de las funciones correspondientes a sus permisos.

2. Dashboard principal

Panel de trabajo

Después de iniciar sesión, el usuario accede al dashboard principal de VentasBar.

Desde esta pantalla se puede visualizar el estado de las mesas del establecimiento y acceder a las diferentes funciones de gestión de la aplicación.

El dashboard constituye la pantalla principal de trabajo desde la que se controla la actividad del bar o restaurante.

Gestión de mesas Ventas Productos Comandas

3. Sistema de cobro

Cobro de la venta

Una vez que el cliente termina su consumición, el sistema permite realizar el cobro de la venta directamente desde el TPV.

Al seleccionar la opción de cobro aparece una pequeña ventana solicitando el efectivo recibido por parte del cliente.

El sistema comprueba automáticamente la cantidad introducida y la compara con el total de la venta.

Mientras el dinero recibido sea inferior al total, el botón Continuar permanece deshabilitado.

Cuando se introduce una cantidad igual o superior al total de la venta, el botón Continuar se habilita y, si se ha entregado más dinero del necesario, el sistema calcula automáticamente el cambio que debe devolverse.

Efectivo recibido Comprobación del importe Cálculo del cambio Confirmación de venta

4. Comandas desde dispositivo móvil

Comandas en tiempo real

El sistema permite que el camarero pueda tomar las comandas directamente desde un dispositivo móvil.

Una vez enviada la comanda, esta se recibe en tiempo real y se clasifica según el destino de los productos: Barra o Cocina.

Cada comanda muestra información como el número de mesa, el nombre del camarero y los productos solicitados.

Desde la pantalla de gestión también existe un botón de imprimir para generar la comanda correspondiente y facilitar su preparación por el personal de barra o cocina.

Dispositivo móvil Barra Cocina WebSocket Impresión
